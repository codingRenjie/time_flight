# Time Flight · 时光航班

面向 12 岁孩子晚间自主时间管理的响应式 Web 应用（MVP v0.1）。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 http://localhost:5173）。平板竖屏体验最佳。

## 首次试用建议

1. 打开 **设置**，保持 **试用模式** 开启（默认已开）——从点击「确认航程」起算 120 分钟，无需等到 19:30。
2. 为快速体验 **超时并行扣减**，可在设置里把「数学巩固」改为 **3 分钟**。
3. 在 **航程** 页排好航段 → **确认航程 · 起飞**。
4. 数学块到点后继续做题，观察下方「后续航段预算」同步减少。
5. 试用结束可在设置或日结页 **重置今日航程**。

## 功能（MVP）

- 燃料盘 + 排航程（拖拽排序、添加学习块）
- 执飞计时 + 超时静默并行扣减后续预算
- 进港后时间不足时的优先级选择
- 自由飞行 + 21:30 日结进港
- 家长设置（窗口、模板、试用模式）
- 本地 IndexedDB 存储
