# Time Pilot 时光机长

Time Pilot 把一段专注时间排成一趟航程。你自己选定开始和结束，把要做的事排进航程，推上油门起飞，做完一项再进港。时间不够或提前做完，系统按固定规则改写后面的任务，不弹窗打断，也不做评价。

线上版本：[https://timepilot.cc](https://timepilot.cc)。数据只存在这台设备的浏览器里，没有账号，也没有云同步。

## 一次航程

默认窗口是 18:30 到 21:30。开始和结束都可以改；结束早于开始时，按跨过午夜计算。可以把一组时间设成下次打开时的默认值。

1. **开始。** 选定这一趟的起止时间。
2. **规划任务。** 任务池里有每次都在的固定任务，也可以新建任务。每个任务时长按 5 分钟调整，最短 5 分钟，最长 180 分钟。页面上的「可规划航程时长」等于航程总长减去全部任务时长。这个数字小于 0 时不能继续，必须先缩短或移出任务。同时选定这一趟驾驶的飞机。
3. **排序。** 拖动任务，决定先后。飞机和总时长在这里不能再改。
4. **起飞。** 按住油门从下向上推到底，停顿片刻后进入第一项任务。
5. **执飞。** 圆环显示这项任务还剩多少分钟。你可以随时按「进港」。提前按，省下的时间会补给后面；超时后再按，多出来的时间已经从余量或后面的任务里扣掉。「未完成」只是一个标签，可以取消，不会跳转。
6. **进港。** 看这项任务的摘要，再确认下一项并起飞。最后一项进港后，航程结束，看到全部任务的完成情况。
7. **取消。** 执飞中可以取消整趟航程。取消不计入完成次数，确认后可以重新开始。

到达结束时刻时，无论当前任务有没有进港，这一趟都会结束。

首页左上角进入徽章墙，右上角进入设置。设置里可以改飞机、固定任务，以及是否允许延长航程。

## 时间怎么流动

所有增减都按整分钟计算。航程里有三种时间：

- **航程总长**：结束时刻减去开始时刻。
- **任务预算**：排进航程时给每项任务的分钟数。执飞中的圆环按这个预算倒计时。
- **余量**：总长减去全部任务之后剩下的分钟。没排满的时间先放在这里，不属于任何一项任务。

任务分两种。

- **固定任务**（默认是「吃水果」和「多邻国」）每次都会出现，不能移出航程，时长可以改。它们不参与下面任何联动：不加时间，也不被扣时间。
- **自建任务**可以移出。提前、超时、延长航程，都只改写还没起飞的自建任务。

### 提前进港

一项任务没用完预算就进港时，省下的整分钟按后面自建任务的顺序，一次给一项加 1 分钟，轮流分完。后面没有自建任务，或者分不完时，剩下的分钟放回余量。

例如数学省下 5 分钟，后面还有英语和语文：英语 +2，语文 +2，再给英语 +1。

### 超时还继续做

到点之后可以继续做，没有确认框。每多出 1 分钟：

1. 先扣余量。
2. 余量扣完后，按后面自建任务的顺序，一次扣一项 1 分钟。
3. 某项被扣到 0，就标成未完成，不再起飞，之后也不再参与扣减。

正在做的这项不会被打断。扣到没有可扣的任务时，计时仍继续，只是后面不再变化。

### 延长航程

设置里可以关闭。默认允许，一次延长 30 分钟，每趟航程只能用一次。结束时刻相应推迟。多出来的分钟平均分给还没起飞的自建任务；正在做的、已经进港的、固定任务都不加。如果后面已经没有自建任务，就只是把结束时刻推迟。

## 飞机和徽章

飞机按累计完成的航程数解锁，和当次飞的是哪一架无关。

| 飞机 | 解锁 |
| --- | --- |
| Cessna 172 | 一开始就能飞 |
| Pilatus PC-12 | 完成 5 次航程 |
| Bombardier Challenger 350 | 完成 15 次航程 |

徽章按「这一架飞机完成了多少次」计算，和上面的解锁次数不是同一套数字。

| 徽章 | 该机型完成次数 |
| --- | --- |
| 铜 | 1 |
| 银 | 5 |
| 金 | 20 |

还没有徽章时，航程页不显示徽章。只有一枚时自动显示那一枚。有多枚时，在徽章墙上点选一枚，首页和航程页都会换成它。完成一趟航程时，如果这架飞机刚升到新等级，结束页会单独展示这枚新徽章。

## 执飞时的环境

执飞页默认是驾驶舱视角的飞行画面，可以换成机翼掠过云层。背景音默认是飞机发动机白噪音，也可以换成雨、雪、瀑布、篝火或一首专注音乐，并能调节音量或关掉。关掉背景音后，油门和选择时间时的短促反馈还在。执飞期间默认保持屏幕常亮。

手机锁屏后，媒体卡片显示剩余时间。暂停键不会真正暂停这一趟航程。

## 本地运行

需要 Node.js 20。

```bash
npm install
npm run dev
```

浏览器打开终端里的地址，默认是 http://localhost:5173 。手机宽度下浏览最接近实际使用。

```bash
npm run build
npm run preview
```

`npm run build` 会先做类型检查，再把静态网站生成到 `dist/`。线上站点直接托管这个目录。
